## 介绍

::key-takeaways

- 配置键变更：`index` → `robots`，`rules` → `groups`，`cacheTtl` → `cacheMaxAgeSeconds`
- 已移除弃用的组合式 API：`defineRobotMeta`、`RobotMeta` 组件
- `nuxt-seo-experiments` 已重命名为 `nuxt-seo-utils`
::

本指南帮助你从 Nuxt SEO v2 RC 迁移到 v2 稳定版。

发布细节见 [公告](/announcement) 文章。

## Nuxt Site Config v3

Nuxt Site Config 是 Nuxt Robots 内部使用的模块。

升级到 v3.0.0 的重大更新通常不会直接影响你的站点，但建议再核对一遍
[破坏性变更](https://github.com/harlan-zw/nuxt-site-config/releases/tag/v3.0.0)。

## Nuxt SEO Utils v6

进入稳定版时，Nuxt SEO experiments 已从 `nuxt-seo-experiments` 重命名为 `nuxt-seo-utils`。

模块最初叫 `nuxt-seo-experiments`，暗示这些功能还不稳定，最终会进入 Nuxt 核心。现在已经不是这样了，因此模块改名以反映这一点。

随着这次重命名，模块范围也扩大到包含 Nuxt SEO 之前提供的零散功能：

- `useBreadcrumbItems()`{lang="ts"} 组合式 API
- 配置：`redirectToCanonicalSiteUrl`
- 配置：`fallbackTitle`
- 配置：`automaticDefaults`

由于 Nuxt SEO Utils 与 Nuxt SEO 模块使用相同的配置键，你的配置无需改动。不过仍建议测试站点，确保一切按预期工作。

## Nuxt Sitemap v7

### 已移除 `inferStaticPagesAsRoutes` 配置

如果你之前把这个值设为 `false`，需要改成下面这样：

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  sitemap: {
-      inferStaticPagesAsRoutes: false,
+      excludeAppSources: ['pages', 'route-rules', 'prerender']
  }
})
```

### 已移除 `dynamicUrlsApiEndpoint` 配置

`sources` 配置支持多个 API 端点，并允许你提供自定义 fetch 选项，请改用它。

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  sitemap: {
-      dynamicUrlsApiEndpoint: '/__sitemap/urls',
+      sources: ['/__sitemap/urls']
  }
})
```

### 已移除 `cacheTtl` 配置

请使用更清晰的 `cacheMaxAgeSeconds` 配置。

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  sitemap: {
-      cacheTtl: 10000,
+      cacheMaxAgeSeconds: 10000
  }
})
```

### 已移除 `index` 路由规则 / Nuxt Content 支持

如果你在路由规则或 Nuxt Content markdown 文件中使用了 `index: false`，需要改成使用 `robots` 键。

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    // 简单规则可以使用 `index` 快捷方式
-    '/secret/**': { index: false },
+    '/secret/**': { robots: false },
  }
})
```

## Nuxt Robots v5

::warning
`index`、`indexable` 和 `rules` 配置选项已不存在。你必须把路由规则迁移到 `robots` 键，把 robots.txt 配置迁移到 `groups`。
::

### 已移除 `rules` 配置

Nuxt Robots v4 提供了向后兼容的 `rules` 配置。由于它已被弃用，现在不再支持。如果你在使用 `rules`，应迁移到 `groups` 配置，或使用 robots.txt 文件。

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  robots: {
-      rules: {},
+      groups: {}
  }
})
```

### 已移除 `defineRobotMeta` 组合式 API

这个组合式 API 在 v4 中已经不做任何事，因为 Nuxt 默认就会启用 robots meta 标签。如果想控制 robot meta 标签规则，请使用 [`useRobotsRule()`{lang="ts"}](/docs/robots/api/use-robots-rule) 组合式 API。

```diff
- defineRobotMeta(true)
+ useRobotsRule(true)
```

### 已移除 `RobotMeta` 组件

这个组件只是 `defineRobotMeta` 的简单包装。如果想控制 robots 规则，请使用 [`useRobotsRule()`{lang="ts"}](/docs/robots/api/use-robots-rule)。

### 已移除 `index`、`indexable` 配置

使用路由规则或 [Nuxt Content](/docs/robots/advanced/content) 配置 robots 时，你可以通过提供 `index` 或 `indexable` 规则来控制 robots 行为。

这些已不再支持，你应该使用 `robots` 键。

```diff [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    // 简单规则可以使用 `index` 快捷方式
-    '/secret/**': { index: false },
+    '/secret/**': { robots: false },
  }
})
```

## :icon{name="i-noto-rocket"} 功能

**配置 `blockAiBots`**：AI 爬虫可能有益，因为它们能帮助用户找到你的站点；但对一些教育站点，或不希望被 AI 爬虫索引的站点，可以用 `blockAiBots` 选项屏蔽它们。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  robots: {
    blockAiBots: true
  }
})
```

这会屏蔽以下 AI 爬虫：`GPTBot`、`ChatGPT-User`、`Claude-Web`、`anthropic-ai`、`Applebot-Extended`、`Bytespider`、`CCBot`、`cohere-ai`、`Diffbot`、`FacebookBot`、`Google-Extended`、`ImagesiftBot`、`PerplexityBot`、`OmigiliBot`、`Omigili`
