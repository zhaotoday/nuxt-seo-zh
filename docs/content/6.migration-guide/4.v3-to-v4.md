## 介绍

Nuxt SEO v4 是一个主版本，把 `nuxt-og-image` 的最低版本提升到 v6，并且（如果使用）要求 `@nuxtjs/i18n` v10+。

其他子模块仍停留在当前主版本，没有破坏性变更。

## 支持

如果迁移卡住，或迁移后出现缺陷，请联系我们。

- [加入 Discord](https://discord.com/invite/5jDAMswWwX)
- [创建 GitHub issue](https://github.com/harlan-zw/nuxt-seo/issues)

## Nuxt OG Image v6

OG Image v6 是这次发布中最大的变化。它引入了新的基于 Rust 的渲染器（Takumi），取消捆绑渲染器依赖，并改变了检测 OG Image 组件的方式。

运行自动化迁移 CLI 来处理大多数变更：

```bash
npx nuxt-og-image migrate v6
```

完整的破坏性变更、新功能和手动迁移步骤，见 [OG Image v6 发行说明](/docs/og-image/releases/v6)。

## Nuxt i18n v10

如果你使用 `@nuxtjs/i18n`，Nuxt SEO v4 现在要求 v10+。这被声明为可选 peer dependency；如果你不使用 i18n，无需任何操作。

## 最低 Nuxt 版本

现在支持的最低 Nuxt 版本是 `3.16.0`。
