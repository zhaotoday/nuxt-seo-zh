每个 SEO 模块都需要你的站点 URL——站点地图、OG 图片、Schema.org 标识符。Site Config 让你设置一次，而不是在各个模块中重复配置。

## 快速设置

对大多数站点，把这些加到 `nuxt.config.ts`：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  site: {
    url: 'https://example.com',
    name: 'My Site'
  }
})
```

就这样。所有模块现在都知道你的规范 URL 和站点名称。

## 可用选项

| 选项 | 用途 | 默认值 |
|--------|---------|---------|
| `url` | 规范站点 URL（SEO 必需） | 开发环境自动检测 |
| `name` | 用于 meta 标签和 Schema.org 的站点名称 | - |
| `description` | 默认 meta 描述 | - |
| `defaultLocale` | 语言代码（例如 `en`） | 自动来自 i18n |
| `indexable` | 允许搜索引擎索引 | 生产环境为 `true` |
| `trailingSlash` | URL 以 `/` 结尾 | `false` |

全部选项见 [完整配置参考](/docs/site-config/api/config)。

## 按环境配置

运行预发或预览环境？使用环境变量，让每次部署都拿到正确的 URL：

```bash
# .env.staging
NUXT_SITE_URL=https://staging.example.com
NUXT_SITE_ENV=staging
```

```bash
# .env.production
NUXT_SITE_URL=https://example.com
NUXT_SITE_ENV=production
```

非生产环境会自动被阻止索引。

::tip
robots 模块会自动阻止非生产环境被索引。预发或预览部署无需手动配置 `noindex`。
::

## 读取 Site Config

使用 `useSiteConfig()`{lang="ts"} 在任何地方访问配置：

```vue
<script setup lang="ts">
const site = useSiteConfig()
// site.url, site.name, site.description, etc.
</script>
```

可在组件、组合式 API 和服务端路由中使用。

## 多租户

一个 Nuxt 应用服务多个域名？Site Config 可以处理：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  site: {
    multiTenancy: [
      {
        hosts: ['example.com', 'www.example.com'],
        config: { name: 'Example', url: 'https://example.com' }
      },
      {
        hosts: ['foo.com', 'www.foo.com'],
        config: { name: 'Foo', url: 'https://foo.com' }
      }
    ]
  }
})
```

正确的配置会根据传入请求的 hostname 加载。

运行时配置见 [多租户指南](/docs/site-config/guides/multi-tenancy)。
