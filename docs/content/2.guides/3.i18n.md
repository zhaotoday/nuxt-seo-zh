所有 Nuxt SEO 模块都会自动与 [@nuxtjs/i18n](https://i18n.nuxtjs.org/) 和 [nuxt-i18n-micro](https://nuxt.com/modules/nuxt-i18n-micro) 集成。你不需要额外配置；安装其中任一模块后，Nuxt SEO 就会检测到集成。

## 示例设置

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    '@nuxtjs/i18n', // 或 'nuxt-i18n-micro'
    '@nuxtjs/seo',
  ],

  site: {
    // 如果没有提供 nuxtSiteConfig 翻译，则使用此回退值
    name: 'My Site',
  },

  i18n: {
    baseUrl: 'https://example.com',
    defaultLocale: 'en',
    strategy: 'prefix_except_default',
    langDir: 'locales/',
    locales: [
      { code: 'en', language: 'en-US', file: 'en.ts' },
      { code: 'fr', language: 'fr-FR', file: 'fr.ts' },
    ],
  },
})
```

## 翻译站点名称和描述

站点名称和描述通常会随语言变化。你可以在语言文件中通过 `nuxtSiteConfig` 键提供翻译值。这些值会覆盖 `nuxt.config.ts` 中设置的 `site.name` 和 `site.description`。

::code-group

```ts [locales/en.ts]
export default {
  nuxtSiteConfig: {
    name: 'My Site',
    description: 'Welcome to my site!',
  },
}
```

```ts [locales/fr.ts]
export default {
  nuxtSiteConfig: {
    name: 'Mon Site',
    description: 'Bienvenue sur mon site!',
  },
}
```

::

所有模块都会自动使用翻译后的值：meta 标签、Schema.org、OG 图片，以及任何出现站点名称或描述的地方。

完整细节见 [Site Config I18n 文档](/docs/site-config/guides/i18n)。

## 每个模块会做什么

使用上面的配置时，各模块会产出以下内容。

### SEO Utils

语言相关的 meta 标签会自动设置在 `<html>`{lang="html"} 元素和 `<head>`{lang="html"} 中。

**英语（`/`）：**

```html
<html lang="en-US">
<head>
  <title>My Site</title>
  <meta property="og:locale" content="en_US">
  <meta property="og:site_name" content="My Site">
  <meta name="description" content="Welcome to my site!">
  <link rel="canonical" href="https://example.com/">
</head>
```

**法语（`/fr`）：**

```html
<html lang="fr-FR">
<head>
  <title>Mon Site</title>
  <meta property="og:locale" content="fr_FR">
  <meta property="og:site_name" content="Mon Site">
  <meta name="description" content="Bienvenue sur mon site!">
  <link rel="canonical" href="https://example.com/fr">
</head>
```

[完整文档](/docs/seo-utils/guides/i18n)

### Sitemap

站点地图模块会生成站点地图索引，每种语言各有一份站点地图：

```xml
<sitemapindex xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <sitemap>
    <loc>https://example.com/__sitemap__/en-US.xml</loc>
  </sitemap>
  <sitemap>
    <loc>https://example.com/__sitemap__/fr-FR.xml</loc>
  </sitemap>
</sitemapindex>
```

每种语言的站点地图都包含在翻译之间建立链接的 `hreflang` 备选项。

[完整文档](/docs/sitemap/guides/i18n)

### Robots

Robots 规则会根据你的 i18n 策略自动扩展，包含带语言前缀的路径。

```txt
User-agent: *
Disallow:

Sitemap: https://example.com/sitemap_index.xml
```

[完整文档](/docs/robots/advanced/i18n)

### Schema.org

Schema.org 会为每种语言创建一个 `WebSite` 实体，并用 `workTranslation` 把它们关联起来：

```json
{
  "@type": "WebSite",
  "name": "My Site",
  "description": "Welcome to my site!",
  "inLanguage": "en-US",
  "url": "https://example.com/",
  "workTranslation": [
    { "@id": "https://example.com/#website" },
    { "@id": "https://example.com/fr#website" }
  ]
}
```

[完整文档](/docs/schema-org/guides/i18n)

**OG Image**：为每种语言生成图片，并使用该语言的站点名称和描述作为默认属性。[完整文档](/docs/og-image/integrations/i18n)

**Site Config**：从你的 i18n 配置中提取 `url`、`defaultLocale` 和 `currentLocale`。`nuxtSiteConfig` 翻译键提供每种语言的 `name` 和 `description`。[完整文档](/docs/site-config/guides/i18n)
