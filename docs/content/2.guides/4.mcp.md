## 工具

### 文档工具

**`get_module_setup`**：获取某个 Nuxt SEO 模块的安装指南。返回安装命令、内容和导航树。

| 参数 | 类型 | 说明 |
|-----------|------|-------------|
| `module` | `string` | `nuxt-seo`、`robots`、`sitemap`、`og-image`、`schema-org`、`link-checker`、`seo-utils`、`site-config` |

```ts
get_module_setup({ module: 'schema-org' })
```

使用 `search_pages_fuzzy` 在其他页面中查找具体内容。

**`list_modules`**：列出所有 Nuxt SEO 模块及其统计信息（stars、downloads、versions）。

```ts
list_modules()
```

### SEO 分析工具

这些工具让 AI 助手可以直接分析和调试 SEO 问题。

**`debug_social_share`**：调试某个 URL 的社交分享卡片。返回解析后的 Open Graph 和 Twitter Card 标签，以及校验警告。

```ts
debug_social_share({ url: 'https://example.com' })
```

返回：`og:title`、`og:description`、`og:image`、Twitter 卡片标签，以及缺失/无效标签的警告。

**`validate_schema`**：验证任意 URL 上的 Schema.org 结构化数据。检测 JSON-LD 和 Microdata 标记。

```ts
validate_schema({ url: 'https://example.com' })
```

返回：所有检测到的 schema、校验错误、警告，以及富摘要资格。

**`analyze_robots_txt`**：抓取并解析任意网站的 robots.txt。

```ts
analyze_robots_txt({ url: 'https://example.com' })
```

返回：原始内容、按 user-agent 解析的规则、sitemap 指令。

**`validate_sitemap`**：校验 XML 站点地图内容是否有错误以及是否合规。

```ts
validate_sitemap({ xml: '<?xml version="1.0"?>...' })
```

返回：校验状态、URL 数量、错误（重复项、无效 URL）、警告。

**`check_meta_tags`**：从 URL 提取并解析 meta 标签。

```ts
check_meta_tags({ url: 'https://example.com' })
```

返回：解析后的 `title`、`description`、`og:*`、`twitter:*`、`canonical`、`robots` 以及其他 meta 标签。

**`convert_html_to_markdown`**：把网页 HTML 转换成干净的 Markdown。

```ts
// 从 URL
convert_html_to_markdown({ url: 'https://example.com' })

// 从 HTML 字符串
convert_html_to_markdown({ html: '<h1>Hello</h1>', extractContent: true })
```

返回：Markdown 内容，以及原始和转换后的大小。

## 资源

**`nuxt-seo://reference`**：一份资源中包含所有模块、配置和 schema.org 模式的完整参考。

**URI：** `nuxt-seo://reference`

包含：

- 带关键配置的模块概览
- 关键组合式 API 快速参考
- 完整的 nuxt.config.ts 示例
- Article、Product、Person、FAQ、Organization 的 Schema.org 模式

**`nuxtseo://modules`**：所有模块及其统计信息（stars、downloads、versions）的列表。

**URI：** `nuxtseo://modules`

## Nuxt SEO Pro MCP

需要代码生成、页面分析或关键词研究？[Nuxt SEO Pro](/pro/dashboard) 额外提供：

- `analyze_page` - 分析 Vue 文件中的 SEO 问题
- `generate_schema_org` - 生成 `useSchemaOrg()`{lang="ts"} 代码
- `generate_og_image_template` - 生成 OG 图片组件
- 内容智能工具（关键词研究、SERP 分析、排名检查）
- 内容生成提示词
