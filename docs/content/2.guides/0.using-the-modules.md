## 介绍

Nuxt SEO 通过 `@nuxtjs/seo` 捆绑了 6 个核心模块。大多数开箱即用，但你可能需要根据站点需求做一些配置。
你也可以单独安装 [Skew Protection](/docs/skew-protection/getting-started/introduction) 和 [AI Ready](/docs/ai-ready/getting-started/introduction) 等独立模块。

::note{icon="i-heroicons-information-circle"}
无论你安装的是 `@nuxtjs/seo`（别名）还是单独安装各个模块，配置方式都相同。每个模块都是独立的，通过自己的选项配置。详情见 [介绍](/docs/nuxt-seo/getting-started/introduction#the-nuxtjsseo-module)。
::

本指南会快速介绍每个模块，以及你需要做什么才能开始使用。

如果想看可运行示例，请查看 [StackBlitz Demo](https://stackblitz.com/edit/nuxt-starter-gfrej6?file=nuxt.config.ts)。

## Sitemap

:ModuleCard{slug="sitemap" class="w-1/2"}

根据应用的 [数据源](/docs/sitemap/getting-started/data-sources)，在 [/sitemap.xml](http://localhost:3000/sitemap.xml) 生成 [站点地图](https://developers.google.com/search/docs/crawling-indexing/sitemaps/overview)。

- 预渲染或只使用静态路由时，无需任何配置就会自动生成站点地图。
- 如果有动态路由，你需要为 [动态 URL](/docs/sitemap/guides/dynamic-urls) 设置处理器。

**I18n 功能**：站点地图模块会自动生成多站点地图，每种语言都有自己的站点地图。

更多信息见 [I18n Sitemap](/docs/sitemap/guides/i18n)。

## Robots

:ModuleCard{slug="robots" class="w-1/2"}

在 [/robots.txt](http://localhost:3000/robots.txt) 生成 [robots.txt](https://developers.google.com/search/docs/crawling-indexing/robots/intro)。

会追加 `<meta name="robots" content="<rule>">`{lang="html"} 和 `X-Robots-Tag` HTTP 响应头。

- 如果你除了 development 和 production 还有其他环境，需要配置 `env` 选项。更多信息见 [禁用索引](/docs/robots/guides/disable-indexing)。
- 默认允许所有 user-agent 访问所有路由。要开始屏蔽路由，见 [禁用页面索引](/docs/robots/guides/disable-page-indexing)。

**I18n 功能**：robots 模块中的任何 `Disallow` 规则都会自动加上语言前缀。

更多信息见 [I18n Robots](/docs/robots/advanced/i18n)。

## OG Image

:ModuleCard{slug="og-image" class="w-1/2"}

为页面生成动态 Open Graph 图片。

- 默认是按需启用的，不配置就不会做任何事。
- 设置方法见 [教程：熟悉 Nuxt OG Image](/docs/og-image/getting-started/getting-familiar-with-nuxt-og-image)。

注意：如果不打算生成动态图片，建议 [禁用此模块](/docs/nuxt-seo/guides/debugging-modules#disabling-modules)。

## Schema.org

:ModuleCard{slug="schema-org" class="w-1/2"}

自动为页面生成 schema.org JSON-LD。

- 为页面提供 [默认 Schema.org](/docs/schema-org/guides/default-schema-org)。
- 也建议为站点 [设置身份信息](/docs/schema-org/guides/setup-identity)。
- 你可以使用 [useSchemaOrg](/docs/schema-org/guides/full-documentation) 按需加入更多 Schema.org。

## Link Checker

:ModuleCard{slug="link-checker" class="w-1/2"}

检查所有链接是否存在可能影响 SEO 的问题。

- 构建站点时会检查链接
- 也可以打开 Nuxt DevTools 中的「Link Checker」标签手动运行

## SEO Utils

:ModuleCard{slug="seo-utils" class="w-1/2"}

一些放不进其他模块的额外 SEO Nuxt 功能。

- 更多信息见 [SEO Utils 介绍](/docs/seo-utils/getting-started/introduction)。
- 自动的文件元数据 [图标](/docs/seo-utils/guides/app-icons) 和 [Open Graph 图片](/docs/seo-utils/guides/open-graph-images)
- 在 nuxt.config 和路由规则中按需使用 [seoMeta](/docs/seo-utils/guides/nuxt-config-seo-meta)
- 为站点自动提供 [默认 meta](/docs/seo-utils/guides/default-meta)
- 为站点自动提供 [回退标题](/docs/seo-utils/guides/fallback-title)
- 按需启用带 Schema.org 支持的 [面包屑](/docs/seo-utils/api/breadcrumbs)

## 共享配置

:ModuleCard{slug="site-config" class="w-1/2"}

[Nuxt Site Config](/docs/site-config/getting-started/introduction) 让你可以在构建时和运行时配置所有 Nuxt SEO 模块，例如在多租户或 i18n 应用中。

::note{icon="i-heroicons-information-circle"}
你不需要手动安装 `nuxt-site-config`。安装任意 Nuxt SEO 模块时都会自动安装它。
::

你应该设置以下配置。从 v5 开始，站点配置不再从 `package.json` 或项目目录推断，因此这些值必须显式设置：

- `url` - 站点的规范 URL，避免重复内容并聚合页面权重。
- `name` - 站点名称，用于标题和 meta 标签。**如果你希望 SEO 输出中包含站点名称，则必填。**
- `description` - 站点描述，用于 meta 标签。
- `defaultLocale` - 站点的默认语言，用于 meta 标签。（如果你使用 `@nuxtjs/i18n` 或 `nuxt-i18n-micro`，可以省略）

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  site: {
    url: 'https://example.com',
    name: 'Awesome Site',
    description: 'Welcome to my awesome site!',
    defaultLocale: 'en', // 如果已安装 @nuxtjs/i18n 或 nuxt-i18n-micro，则不需要
  }
})
```

**I18n 功能**：你可以根据当前语言动态设置站点配置。

这在根据用户当前所在页面设置 `url` 和 `name` 时很有用。

更多信息见 [I18n Site Config](/docs/site-config/guides/i18n)。
