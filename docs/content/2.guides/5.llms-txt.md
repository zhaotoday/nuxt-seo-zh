当 AI 工具理解你的技术栈时，它们会工作得更好。LLMs.txt 为 Cursor、Windsurf、[ChatGPT](https://chatgpt.com) 和 Claude 提供关于 Nuxt SEO 的结构化文档，让你少花时间解释上下文，多花时间构建。

## 可用路由

我们提供两种针对 AI 消费优化的文档格式：

- **/llms.txt** - 所有模块和文档链接的结构化概览（约 5K tokens）
- **/llms-full.txt** - 完整文档及 markdown 格式的示例

::note{icon="i-heroicons-light-bulb"}
从 `/llms.txt` 开始。当你需要完整示例，且 AI 工具支持大上下文（200K+ tokens）时，再使用 `/llms-full.txt`。
::

## 用法

### Cursor

在聊天中直接引用文档，或用 `@docs` 加入项目上下文：

```text
@https://nuxtseo.com/llms.txt
```

[Cursor Web 和文档搜索 →](https://docs.cursor.com/en/context/@-symbols/@-docs)

### Windsurf

使用 `@docs` 引用这些 URL，或把它们加入工作区规则：

```text
@https://nuxtseo.com/llms.txt
```

[Windsurf Web 和文档搜索 →](https://docs.windsurf.com/windsurf/cascade/web-search)

### ChatGPT / Claude

在提示词中粘贴 URL：

```text
Using Nuxt SEO docs from https://nuxtseo.com/llms.txt, help me configure...
```

::warning{icon="i-heroicons-exclamation-triangle"}
**请手动输入 @** - 在 Cursor 和 Windsurf 中，`@` 符号必须手打。复制粘贴会破坏上下文识别。
::
