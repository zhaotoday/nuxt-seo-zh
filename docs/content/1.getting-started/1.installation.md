## 安装 Nuxt SEO 别名模块

`@nuxtjs/seo` 是一个别名模块，把核心 SEO 模块打包成一次安装。

:ModuleInstall{name="@nuxtjs/seo"}

## 我应该安装哪个包？

新项目如果需要标准 SEO 技术栈，请使用 `@nuxtjs/seo`：Sitemap、Robots、OG Image、Schema.org、Link Checker、SEO Utils 和 Site Config。

只有在你想减少依赖，或需要自己锁定模块版本时，才单独安装各个模块。

::tip{icon="i-heroicons-arrow-path"}
升级现有项目？先查看 [更新模块](/docs/nuxt-seo/guides/updating-modules) 指南，如果跨越了主版本，再按对应的 [迁移指南](/docs/nuxt-seo/migration-guide/v4-to-v5) 操作。
::

::tip
使用 [skilld](https://github.com/harlan-zw/skilld) 为这个包生成 Agent Skill：
```bash
npx skilld add @nuxtjs/seo
```
::

### 单独安装模块

如果你只需要特定模块，或想自己控制版本锁定，请分别安装。每个模块都可以独立工作，也可以按需组合。

::note{icon="i-heroicons-information-circle"}
安装任意 SEO 模块时都会自动安装 `nuxt-site-config`。你不需要手动添加它。
::

:AllModules

### 独立模块

`@nuxtjs/seo` 不包含这些模块，但你可以和它一起安装，也可以单独使用。

**Skew Protection**：用持久化资源和即时更新解决 Nuxt 版本偏移。

:ModuleInstall{name="nuxt-skew-protection"}

配置选项见 [Skew Protection 文档](/docs/skew-protection/getting-started/introduction)。

**AI Ready**：为 Nuxt 站点提供符合最佳实践的 AI 与 LLM 可发现性。会生成 `llms.txt`、`llms-full.txt` 和 `robots.txt` 中的 AI 指令。

:ModuleInstall{name="nuxt-ai-ready"}

配置选项见 [AI Ready 文档](/docs/ai-ready/getting-started/introduction)。

## 下一步
