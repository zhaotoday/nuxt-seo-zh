## 为什么使用 Nuxt SEO？

[Nuxt SEO](https://nuxtseo.com) 是一套面向 Nuxt 社区、由社区共建的 SEO 模块、工具与教程生态。技术 SEO 需要很多环节同时运转：站点地图、robots.txt、Schema.org、OG 图片、meta 标签、死链。Nuxt SEO 为每一项都提供了模块，因此你可以单独安装，也可以一次装齐。

## 从这里开始

对大多数 Nuxt 站点：

1. 安装 [`@nuxtjs/seo`](/docs/nuxt-seo/getting-started/installation)。
2. 设置生产环境的 `site.url` 和 `site.name`。
3. 在生产环境访问 `/sitemap.xml`、`/robots.txt` 和一个真实页面，确认生成结果。
4. 上线前使用 [SEO 检查清单](/learn-seo/checklist)。

如果只需要某一项功能，请安装对应的独立模块。例如只需要站点地图时，使用 `@nuxtjs/sitemap`。

## 功能特性

### 🤖 抓取控制

自动生成 `robots.txt`、`<meta name="robots">`{lang="html"} 标签和 `X-Robots-Tag` 响应头，管理搜索引擎如何访问你的站点。

- [Robots 文档](/docs/robots/getting-started/introduction)

### 📄 站点地图

根据应用数据源自动生成 `sitemap.xml`，并支持 i18n 站点的多站点地图。

- [Sitemap 文档](/docs/sitemap/getting-started/introduction)

### 🖼️ OG 图片

为每个页面动态生成 Open Graph 图片，无需手工设计。

- [OG Image 文档](/docs/og-image/getting-started/introduction)

### 🔎 结构化数据

自动生成带合理默认值的 Schema.org JSON-LD，并支持按需启用更丰富的 schema。

- [Schema.org 文档](/docs/schema-org/getting-started/introduction)

### ✅ 链接检查

构建时检测死链，并集成 [ESLint](https://eslint.org) 与 DevTools。

- [Link Checker 文档](/docs/link-checker/getting-started/introduction)

### △ SEO 工具集

自动处理 favicon、默认 meta 标签、面包屑和社交分享链接。

- [SEO Utils 文档](/docs/seo-utils/getting-started/introduction)

## 模块

:AllModules

每个模块都可以单独使用。你可以只安装需要的模块（例如 Sitemap 和 Robots），也可以用 `@nuxtjs/seo` 一次拿到核心模块。无论哪种方式，配置、组合式 API 和功能都完全相同。

### 独立模块

`@nuxtjs/seo` 捆绑包不包含这些模块，但你可以单独安装，并与它一起使用。

- **[Skew Protection](/docs/skew-protection/getting-started/introduction)**：用持久化资源和即时更新解决 Nuxt 版本偏移。
- **[AI Ready](/docs/ai-ready/getting-started/introduction)**：为 Nuxt 站点提供符合最佳实践的 AI 与 LLM 可发现性。

### Site Config

所有模块都需要站点 URL 来生成 canonical 链接和站点地图。Site Config 确保所有模块共享正确的配置。你不需要手动安装这个模块；安装任意 SEO 模块时都会自动安装它。

只需设置一次：

```ts
export default defineNuxtConfig({
  site: {
    url: 'https://example.com',
    name: 'My Site'
  }
})
```

每个模块都会使用这些值，无需重复配置。

## `@nuxtjs/seo` 模块

:ModuleCard{slug="nuxt-seo" class="w-1/2"}

`@nuxtjs/seo` 包只是一个别名，用来一次性安装核心 SEO 模块。它本身不包含任何逻辑。

```bash
npx nuxt module add @nuxtjs/seo
```

```ts
// 它做的事情就这些！
export default defineNuxtModule<ModuleOptions>({
  moduleDependencies: {
    '@nuxtjs/robots': { version: '>=6.0' },
    '@nuxtjs/sitemap': { version: '>=8.0' },
    'nuxt-link-checker': { version: '>=5.0' },
    'nuxt-og-image': { version: '>=6.2' },
    'nuxt-schema-org': { version: '>=6.0' },
    'nuxt-seo-utils': { version: '>=8.1' },
    'nuxt-site-config': { version: '>=4.0' },
  },
})
```

**@nuxtjs/seo 与单独安装模块**：两种方式给你的是完全相同的模块和功能。唯一区别是安装方式。

- **使用 `@nuxtjs/seo`**：如果你想一次安装核心模块。这是最容易上手的方式。
- **单独安装**：如果你只需要特定模块（例如 Sitemap 和 Robots），或想把每个模块锁定到特定版本。
- **独立模块**（如 Skew Protection 和 AI Ready）可以和上面任意一种方式一起使用。

::note{icon="i-heroicons-information-circle"}
无论选择哪种方式，配置、组合式 API 和 Nuxt Content 集成的工作方式都完全相同。所有模块文档同时适用于这两种方式。
::
